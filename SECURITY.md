# Security

Report a vulnerability privately, through GitHub's private vulnerability reporting: the
repository's **Security** tab, then **Report a vulnerability**. Please do not open a public
issue for it. The NCI SI MCP project coordinator receives the report and answers it there.

What the server holds and sends upstream (the EVS licence key, the caDSR credential) and how
it keeps them out of logs, errors and results is specified in
[docs/specification.md](docs/specification.md) (A7.5).
